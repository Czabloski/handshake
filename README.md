# Handshake Monitor

Serviço em Python que monitora periodicamente o endpoint de handshake do CPI e registra os resultados em log.

---

## 🛠️ Como usar

### Rodar o serviço

```bash
python3 main.py
```

### Parar o serviço

- Pressione `CTRL + C` no terminal.

### Log

- Todos os requests são registrados em:

```
logs/handshake.log
```

- Sucessos aparecem como `INFO` e falhas como `ERROR`.
